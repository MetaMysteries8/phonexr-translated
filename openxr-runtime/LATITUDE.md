# PhoneXR Latitude runtime work

The currently bundled `phonexr-runtime.apk` is a patched Monado build, not an independent runtime. The attached Monado snapshot `2773473de89567771114d6818f15cfd7c8216822` accepts `monado-phonexr.patch` in a dry run. Keep the Monado license notices and upstream attribution when producing a Latitude-branded build.

The shipped arm64 `libopenxr_monado.so`, `libmonado-service.so`, and `libzxingcpp_android.so` have `0x1000` PT_LOAD alignment. Android's 16 KiB page devices need at least `0x4000`; `zipalign -P 16` only aligns the APK entries. `check_elf_pages.py` rejects incompatible runtime APKs, and the app disables installing this bundle on 16 KiB page devices. A separately installed, newer compatible runtime may still be selected in OpenXR Runtime Broker.

To make a compatible source build, apply `monado-phonexr.patch` and `monado-16k.patch` to a pinned Monado checkout, configure all native dependencies (including ZXing) with Android NDK r28+ or 16 KiB ELF linker flags, produce the out-of-process arm64 APK, and run `python3 openxr-runtime/check_elf_pages.py path/to/runtime.apk` before `build_runtime_apk.py --apk ...`. Verify the runtime manifest package and broker registration, headset rendering, and controller bridge on the Galaxy S25. The source and patch alone are not a tested new XR runtime; third-party Quest APKs may require vendor libraries, entitlement, or extensions that this runtime does not implement.

The app keeps its current package ID and existing runtime broker package until signing, patched game permissions, and migration have been tested. The launcher label and offline UI now use Latitude. Account, Friends, Calls, and the server-backed Elix client were removed; local headset features and the public store do not require sign-in.
